# Brew & Bean Cafe - Cafe Shop Menu

CSE326 CA1 Project (Lovely Professional University)

A simple responsive cafe website where customers can browse the menu, choose a flavour and toppings, add items to a cart and place an order.

## Pages

A one-page website. `index.html` has these sections, reached from the navbar or by scrolling:

- Home
- Menu (category filter, flavours, toppings)
- Cart
- Gallery (`images/` folder)
- Contact (form with validation, Google Map, cafe timings)

## Technologies Used

- HTML5 (semantic tags, forms, table, SVG)
- CSS3 (variables, Flexbox, Grid, media query, transition, animation)
- JavaScript (arrays, objects, functions, DOM, events, localStorage)
- GitHub and GitHub Pages

## How to Run

Open `index.html` in any browser. No installation is needed.
